What MCP is

MCP (Model Context Protocol) is an open standard that lets an AI app use tools on another system. Here, the tools are your knowledge base and a test version of your support bot. You ask in plain words, for example “Which documents are expired?”, and the AI calls the right tool.

Each connection works for one account, with either read-only or read-and-write access. Nothing an AI does here sends a message to a customer.

What a connected AI can do

ToolAccessWhat it does
list_documentsReadLists documents with their status (active, scheduled, expired), dates, and how often customer questions used them. “List knowledge nobody has used.”
get_documentReadReads one document in full, by key (like product-017) or ID. “Show me product-017.”
find_similarReadFinds documents that probably say the same thing (85%+ similar), to avoid duplicates. “Do we already have something about refunds?”
test_botReadAsks the real support bot a customer question without sending anything to customers. Returns the reply, whether it would hand over to staff, and the knowledge it used. “How would the bot answer ‘how much is it?’”
upsert_documentWriteAdds a document, or replaces one with the same key. Refuses a near-copy of an existing document unless told otherwise. Can set start and end dates. “Add an FAQ: Do you ship abroad? Yes, to…”
delete_documentWriteDeletes a document. A copy is kept in the audit log so it can be restored. “Delete the old summer promotion.”

Staying safe

  • Start with read only. Give write access only when you want the AI to change what customers are told.
  • Treat a token like a password: keep it out of chats, screenshots and shared files. Lost one? Revoke it and create another.
  • Ask the AI to show a change before it saves it, then check the answer with test_bot.
  • Every change and deletion is recorded with the old version, so a mistake can be undone.
  • Limits: 60 calls a minute per connection, and 10 bot tests a minute per account.
